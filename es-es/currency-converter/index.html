Una conversión de referencia rápida

Este convertidor calcula una tasa cruzada a partir del último conjunto de datos de tasa de referencia disponible. Es útil para estimaciones y comparaciones, pero un banco, tarjeta o servicio de cambio puede ofrecer una tasa de transacción diferente.

La fecha mostrada le indica qué día de mercado representan los datos de referencia.
