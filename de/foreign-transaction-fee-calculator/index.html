Was Dynamic Currency Conversion bedeutet

DCC ist ein Händler- oder Geldautomatenangebot zur Umrechnung der Transaktion in Ihre Heimatwährung, bevor sie Ihre Karte erreicht. Wenn Sie stattdessen in der Landeswährung bezahlen, überlassen Sie die Währungsumrechnung Ihrem Kartenanbieter.

Der Rechner vergleicht den von Ihnen eingegebenen Gesamtbetrag DCC mit einer Schätzung, die auf dem Referenzwechselkurs, Ihrer prozentualen Auslandstransaktionsgebühr und Ihrer Festgebühr basiert.

Was diese Schätzung nicht wissen kann

Ihre Bank, Ihr Kartennetzwerk, Ihr Händler oder Ihr Geldautomat verwenden möglicherweise einen anderen Wechselkurs oder erheben eine andere Gebühr, die Sie nicht eingegeben haben. Eine feste Geldautomatengebühr unterscheidet sich von einer prozentualen Gebühr für Auslandstransaktionen.

Hierbei handelt es sich um einen informativen Vergleich der eingegebenen Werte, nicht um eine Finanzberatung oder um eine Zusage über den endgültigen berechneten Betrag.

Ein anderer Vergleich?

Use the Exchange Rate Markup Calculator when you simply want to compare an exchange quote with the reference result. Use the Währungsrechner for a direct two-currency estimate.

Referenzkurs und Datum

Referenzkurse bieten einen neutralen Vergleichspunkt und keinen garantierten Transaktionskurs. Das Ergebnis zeigt das von der Referenzkurs-API Frankfurter zurückgegebene Marktdatum.
