Offline-Wechselkursführer

Offline-Währungsumrechner: So funktionieren gespeicherte Kurse

Ein Konverter kann ohne Internet weiterarbeiten, indem er die neuesten Wechselkurse verwendet, die er erfolgreich auf Ihrem Gerät gespeichert hat. Diese Tarife sind nützliche Referenzdaten – sie bleiben jedoch an ihr ursprüngliches Datum gebunden, bis die App sie online aktualisieren kann.

Die einfache Version

Von der Online-Aktualisierung bis zur Offline-Konvertierung

Wenn Sie einen Tarif sparen, bleibt er nicht für immer bestehen. Es wird eine veraltete lokale Kopie erstellt, die wiederverwendet werden kann, wenn das Netzwerk nicht verfügbar ist.

1

Verbinden und aktualisieren

Die App fordert den neuesten verfügbaren Referenztarifdatensatz an, zeichnet dessen Tarifdatum auf und spart Zeit.

2

Behalten Sie den letzten Erfolg

Nach erfolgreicher Anfrage wird der Datensatz lokal gespeichert. Wenn eine spätere Anfrage fehlschlägt, bleibt die vorherige Arbeitskopie verfügbar.

3

Konvertieren ohne Internet

Im Offline-Modus verwenden Konvertierungen diesen gespeicherten Datensatz und zeigen zusammen mit dem Tarifdatum an, dass zwischengespeicherte Daten verwendet werden.

Was ein gespeicherter Offline-Tarif bedeutet

Die gespeicherten Daten sind eine Momentaufnahme der letzten erfolgreichen Referenzratenreaktion. Es kann Umrechnungen ohne Netzwerkverbindung berechnen, die Zahlen werden jedoch nicht aktualisiert, während das Gerät offline ist.

Überprüfen Sie immer das angezeigte Tarifdatum. Ein Ergebnis auf Basis der gestrigen Kurse mag für die Planung noch nützlich sein, ist aber kein Versprechen für den Kurs, den eine Bank, ein Kartenanbieter oder eine Wechselstube heute anbieten wird.

Was passiert, wenn das Internet zurückkehrt?

Balkan Converter verwendet einen gemeinsam genutzten lokalen Rate-Cache für die normale Konvertierung und die Vorbereitung gespeicherter Sätze. Eine erfolgreiche Online-Aktualisierung ersetzt den älteren zwischengespeicherten Datensatz, aktualisiert sein Datum und spart Zeit.

Wenn die Aktualisierung fehlschlägt, greift die App auf die zuvor zwischengespeicherten Raten zurück, anstatt sie zu löschen.

Bereiten Sie einen gespeicherten Satz für die Offline-Verwendung vor

Erstellen oder öffnen Sie in der Android-App einen gespeicherten Satz für die von Ihnen benötigten Währungen. Wählen Sie, während die Verbindung besteht Sparen Sie Preise offline. Die App aktualisiert den freigegebenen Kursdatensatz und bestätigt die Bereitschaft, wenn der gespeicherte Cache alle Währungen in diesem Satz enthält.

Es gibt keine separate Datei für eingefrorene Tarife für jede Reise. Durch das Vorbereiten eines weiteren Satzes wird derselbe Cache aktualisiert, der an anderer Stelle in der App verwendet wird.

Nützlich über die Reise hinaus

Die Offline-Konvertierung kann bei einer schlechten Verbindung, einer Roaming-Unterbrechung, einem vorübergehenden Dienstausfall oder in jeder Situation hilfreich sein, in der eine schnelle Referenzschätzung nützlicher ist als kein Ergebnis.
