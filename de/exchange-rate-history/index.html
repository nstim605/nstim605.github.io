Was historische Referenzkurse zeigen

Jeder Punkt stellt den veröffentlichten Referenzwechselkurs für ein Datum dar. Minimum, Maximum und Durchschnitt fassen den ausgewählten Zeitraum zusammen; es sind keine Prognosen.

Referenzkurse können von den Kursen einer Bank, Karte, eines Geldtransferdienstes oder einer Wechselstube abweichen, da die Anbieter möglicherweise Gebühren oder einen Spread erheben.

Termine und Trends

Verwenden Sie das Diagramm, um Richtung und Variation zu erkennen, nicht um die nächste Bewegung vorherzusagen. Einige Anbieter veröffentlichen nicht an jedem Kalendertag. Wenn die API Daten von einem anderen verfügbaren Datum zurückgibt, meldet die Suche das tatsächliche Datendatum, anstatt es als den von Ihnen ausgewählten Tag darzustellen.

For a current conversion, use the Währungsrechner. To compare an exchange offer, use the Markup Calculator.
