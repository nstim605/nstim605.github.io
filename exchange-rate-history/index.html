What historical reference rates show

Each point represents the published reference rate for one date. The minimum, maximum and average summarize the selected period; they are not forecasts.

Reference rates can differ from the rate offered by a bank, card, money-transfer service or exchange office because providers may add fees or a spread.

Dates and trends

Use the chart to see direction and variation, not to predict the next move. Some providers do not publish on every calendar day. If the API returns data from another available date, the lookup reports that actual data date instead of presenting it as the day you selected.

For a current conversion, use the Currency Converter. To compare an exchange offer, use the Markup Calculator.
