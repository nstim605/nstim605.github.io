Dynamic Currency Conversion 是什麼意思

DCC 是商家或 ATM 提供的服務，可在交易到達您的銀行卡之前將其轉換為您的本國貨幣。如果使用當地貨幣付款，則將貨幣轉換留給您的卡片提供者。

計算器會將您輸入的完整 DCC 金額與基於參考匯率、國外交易費百分比和固定費用的估算值進行比較。

這個估計無法知道什麼

您的銀行、卡片網路、商家或 ATM 可能會使用不同的匯率或收取您未輸入的其他費用。固定 ATM 費用與國外交易百分比費用是分開的。

這是對輸入值的資訊比較，而不是財務建議或最終收費金額的承諾。

不同的比較？

使用 匯率加價計算器 當您只想將交易所報價與參考結果進行比較時。使用 貨幣換算 直接進行兩種貨幣估算。

參考利率和日期

參考匯率提供中性比較點，而不是保證交易匯率。結果顯示 Frankfurter 參考利率 API 回傳的市場日期。
