Tarif de référence :

Une estimation rapide, pas un planificateur de voyage

Ce calculateur ajoute vos coûts quotidiens approximatifs pour le nombre de jours saisi, inclut les coûts fixes, puis applique le tampon de pourcentage facultatif.

Utilisez-le pour établir un budget de départ pratique. Les prix réels, les frais de carte et les taux de change peuvent changer.

Comment fonctionne la conversion de devises

Le budget final en devise de destination est converti avec le dernier taux de référence Frankfurter disponible. La date et la source du tarif apparaissent avec chaque résultat.

Outils de change utiles pour un voyage

Compare several amounts with the Multi-Currency Converter, make a quick conversion with the Convertisseur de devises, or learn how the Android app handles offline currency conversion.

Que faut-il inclure

L'hébergement, les repas, les transports locaux et les activités sont des montants journaliers. Ajoutez les vols, les pass ferroviaires ou d'autres dépenses ponctuelles dans les frais de voyage fixes.
