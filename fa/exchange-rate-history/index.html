تاریخ ها و روندها

از نمودار برای دیدن جهت و تغییرات استفاده کنید، نه برای پیش بینی حرکت بعدی. برخی از ارائه دهندگان در هر روز تقویم منتشر نمی کنند. اگر API داده‌ها را از تاریخ موجود دیگری برمی‌گرداند، جستجوگر به‌جای ارائه آن به‌عنوان روزی که انتخاب کرده‌اید، تاریخ واقعی داده را گزارش می‌کند.

برای تبدیل با تازه‌ترین نرخ موجود از مبدل ارز استفاده کنید. برای مقایسه پیشنهاد صرافی با نتیجه نرخ مرجع، ماشین‌حساب اختلاف نرخ را باز کنید.
