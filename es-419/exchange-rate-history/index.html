Lo que muestran las tasas de referencia históricas

Cada punto representa el tipo de referencia publicado para una fecha. El mínimo, máximo y promedio resumen el período seleccionado; no son pronósticos.

Las tasas de referencia pueden diferir de la tasa ofrecida por un banco, tarjeta, servicio de transferencia de dinero u oficina de cambio porque los proveedores pueden agregar tarifas o un margen.

Fechas y tendencias

Utilice el gráfico para ver la dirección y la variación, no para predecir el próximo movimiento. Algunos proveedores no publican todos los días naturales. Si la API devuelve datos de otra fecha disponible, la búsqueda informa esa fecha de datos real en lugar de presentarla como el día que usted seleccionó.

For a current conversion, use the Convertidor de moneda. To compare an exchange offer, use the Markup Calculator.
