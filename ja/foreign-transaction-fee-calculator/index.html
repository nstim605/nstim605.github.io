Dynamic Currency Conversion の意味

DCC は、カードが届く前に取引を自国通貨に換算する販売者または ATM のオファーです。現地通貨で支払う場合、通貨換算はカードプロバイダーに委ねられます。

計算機は、入力した合計金額 DCC を、参照レート、海外取引手数料の割合、および固定手数料に基づく推定値と比較します。

この推定では分からないこと

銀行、カード ネットワーク、販売業者、または ATM では、異なる為替レートが使用されたり、入力していない別の手数料が請求されたりする場合があります。固定の ATM 手数料は、パーセンテージの外国取引手数料とは別のものです。

これは入力された値の情報比較であり、財務上のアドバイスや最終的な請求額の約束ではありません。

違う比較？

Use the Exchange Rate Markup Calculator when you simply want to compare an exchange quote with the reference result. Use the 通貨換算ツール for a direct two-currency estimate.

参照レートと日付

参照レートは中立的な比較ポイントを提供するものであり、保証された取引レートではありません。結果には、Frankfurter 参照レート API によって返された市場日付が表示されます。
