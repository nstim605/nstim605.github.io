Offline exchange-rate guide

Offline Currency Converter: How Saved Rates Work

A converter can keep working without internet by using the latest exchange rates it successfully saved on your device. Those rates are useful reference data—but they remain tied to their original date until the app can refresh them online.

The simple version

From online refresh to offline conversion

Saving a rate does not make it live forever. It creates a dated local copy that can be reused when the network is unavailable.

1

Connect and refresh

The app requests the latest available reference-rate dataset and records its rate date and save time.

2

Keep the last success

After a successful request, the dataset is stored locally. If a later request fails, the previous working copy remains available.

3

Convert without internet

When offline, conversions use that saved dataset and show that cached data is being used, together with the rate date.

What a saved offline rate means

The saved data is a snapshot of the most recent successful reference-rate response. It can calculate conversions without a network connection, but the numbers do not update while the device is offline.

Always check the displayed rate date. A result based on yesterday’s rates may still be useful for planning, but it is not a promise of the rate a bank, card provider, or exchange office will offer today.

What happens when internet returns?

BALCO Converter uses one shared local rate cache for normal conversion and Saved Set preparation. A successful online refresh replaces the older cached dataset and updates its date and save time.

If the refresh fails, the app falls back to the previous cached rates instead of deleting them.

Prepare a Saved Set for offline use

In the Android app, create or open a Saved Set for the currencies you need. While connected, choose Save rates offline. The app refreshes the shared rate dataset and confirms readiness when the saved cache contains every currency in that set.

There is no separate frozen rate file for each trip. Preparing another set refreshes the same cache used elsewhere in the app.

Useful beyond travel

Offline conversion can help during a poor connection, roaming disruption, a temporary service outage, or any situation where a quick reference estimate is more useful than no result.

For quick access to the latest cached pair, see the Android currency widget guide. For online comparisons, use the Currency Converter, compare several results in the Multi-Currency Converter, or check a provider’s offer with the Exchange Rate Markup Calculator.
