动态货币转换（DCC）是什么

DCC 是商家或 ATM 提供的服务，可在交易到达您的银行卡之前将其转换为您的本国货币。如果使用当地货币付款，则将货币转换留给您的卡提供商。

计算器会将您输入的 DCC 最终金额与按参考汇率、境外交易手续费比例和固定费用得出的估算金额比较。

这个估计无法知道什么

银行、卡组织、商家或 ATM 可能采用不同汇率，或收取未输入的其他费用。固定 ATM 费用与按比例收取的境外交易手续费分开计算。

这是对输入值的信息比较，而不是财务建议或最终收费金额的承诺。

不同的比较？

如果只想比较兑换报价与参考汇率结果，请使用汇率差额计算器。如需在两种货币之间进行普通换算，请打开货币换算器。

参考汇率和日期

参考汇率提供中立的比较基准，并不保证实际成交汇率。结果会显示 Frankfurter 参考汇率 API 返回的市场日期。
