Guida offline ai tassi di cambio

Convertitore di valuta offline: come funzionano i tassi salvati

Un convertitore può continuare a funzionare senza Internet utilizzando gli ultimi tassi di cambio salvati con successo sul tuo dispositivo. Queste tariffe sono dati di riferimento utili, ma rimangono legate alla data originale finché l'app non le aggiorna online.

La versione semplice

Dall'aggiornamento online alla conversione offline

Salvare una tariffa non la fa vivere per sempre. Crea una copia locale datata che può essere riutilizzata quando la rete non è disponibile.

1

Connettiti e aggiorna

L'app richiede l'ultimo set di dati disponibile sul tasso di riferimento e registra la data del tasso e fa risparmiare tempo.

2

Mantieni l'ultimo successo

Dopo una richiesta andata a buon fine, il set di dati viene archiviato localmente. Se una richiesta successiva fallisce, la copia di lavoro precedente rimane disponibile.

3

Converti senza Internet

Quando sei offline, le conversioni utilizzano il set di dati salvato e mostrano che vengono utilizzati i dati memorizzati nella cache, insieme alla data della tariffa.

Cosa significa tariffa offline salvata

I dati salvati sono un'istantanea della più recente risposta positiva del tasso di riferimento. Può calcolare le conversioni senza una connessione di rete, ma i numeri non si aggiornano mentre il dispositivo è offline.

Controlla sempre la data della tariffa visualizzata. Un risultato basato sui tassi di ieri può essere ancora utile per la pianificazione, ma non è una promessa del tasso che una banca, un fornitore di carte o un ufficio di cambio offrirà oggi.

Cosa succederà quando tornerà Internet?

Balkan Converter utilizza una cache della velocità locale condivisa per la conversione normale e la preparazione del set salvato. Un aggiornamento online riuscito sostituisce il vecchio set di dati memorizzato nella cache, ne aggiorna la data e fa risparmiare tempo.

Se l'aggiornamento fallisce, l'app torna alle tariffe memorizzate nella cache precedenti invece di eliminarle.

Prepara un set salvato per l'utilizzo offline

Nell'app Android, crea o apri un set salvato per le valute che ti servono. Mentre sei connesso, scegli Salva le tariffe offline. L'app aggiorna il set di dati sui tassi condivisi e conferma l'idoneità quando la cache salvata contiene tutte le valute presenti in quel set.

Non esiste un file tariffario congelato separato per ciascun viaggio. La preparazione di un altro set aggiorna la stessa cache utilizzata altrove nell'app.

Utile oltre il viaggio

La conversione offline può essere utile in caso di connessione debole, interruzione del roaming, interruzione temporanea del servizio o qualsiasi situazione in cui un preventivo di riferimento rapido è più utile di nessun risultato.
