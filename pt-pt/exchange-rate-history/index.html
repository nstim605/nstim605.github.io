O que as taxas de referência históricas mostram

Cada ponto representa a taxa de referência publicada numa data. O mínimo, o máximo e a média resumem o período selecionado; não são previsões.

As taxas de referência podem diferir das oferecidas por bancos, cartões, serviços de transferência ou casas de câmbio, pois estes prestadores podem cobrar comissões ou aplicar uma margem.

Datas e tendências

Utilize o gráfico para observar a direção e a variação, não para prever o movimento seguinte. Alguns prestadores não publicam dados em todos os dias de calendário. Se a API devolver dados de outra data disponível, a consulta indica essa data efetiva em vez de a apresentar como o dia selecionado.

Para converter com a taxa mais recente disponível, utilize o conversor de moedas. Para comparar uma oferta de câmbio com o resultado de referência, abra a calculadora de diferença cambial.
