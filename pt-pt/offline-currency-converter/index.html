Guia de taxas de câmbio off-line

Conversor de moeda offline: como funcionam as taxas salvas

Um conversor pode continuar funcionando sem internet usando as taxas de câmbio mais recentes salvas com sucesso em seu dispositivo. Essas taxas são dados de referência úteis, mas permanecem vinculadas à data original até que o aplicativo possa atualizá-las online.

A versão simples

Da atualização online à conversão offline

Economizar uma taxa não a faz durar para sempre. Ele cria uma cópia local datada que pode ser reutilizada quando a rede estiver indisponível.

1

Conecte e atualize

O aplicativo solicita o conjunto de dados de taxa de referência mais recente disponível e registra a data da taxa e economiza tempo.

2

Mantenha o último sucesso

Após uma solicitação bem-sucedida, o conjunto de dados é armazenado localmente. Se uma solicitação posterior falhar, a cópia de trabalho anterior permanecerá disponível.

3

Converta sem internet

Quando off-line, as conversões usam esse conjunto de dados salvo e mostram que os dados armazenados em cache estão sendo usados, juntamente com a data da taxa.

O que significa uma tarifa off-line salva

Os dados salvos são um instantâneo da resposta bem-sucedida mais recente da taxa de referência. Ele pode calcular conversões sem conexão de rede, mas os números não são atualizados enquanto o dispositivo está offline.

Verifique sempre a data da taxa exibida. Um resultado baseado nas taxas de ontem ainda pode ser útil para o planejamento, mas não é uma promessa da taxa que um banco, operadora de cartão ou casa de câmbio oferecerá hoje.

O que acontece quando a internet retorna?

Balkan Converter usa um cache de taxa local compartilhado para conversão normal e preparação de conjunto salvo. Uma atualização online bem-sucedida substitui o conjunto de dados armazenado em cache mais antigo e atualiza sua data e economiza tempo.

Se a atualização falhar, o aplicativo retornará às taxas armazenadas em cache anteriores em vez de excluí-las.

Prepare um conjunto salvo para uso offline

No aplicativo Android, crie ou abra um Conjunto salvo para as moedas necessárias. Enquanto estiver conectado, escolha Economize tarifas off-line. O aplicativo atualiza o conjunto de dados de taxas compartilhadas e confirma a prontidão quando o cache salvo contém todas as moedas desse conjunto.

Não existe um arquivo separado de tarifas congeladas para cada viagem. Preparar outro conjunto atualiza o mesmo cache usado em outras partes do aplicativo.

Útil além das viagens

A conversão offline pode ajudar durante uma conexão ruim, interrupção de roaming, interrupção temporária do serviço ou qualquer situação em que uma estimativa de referência rápida seja mais útil do que nenhum resultado.
