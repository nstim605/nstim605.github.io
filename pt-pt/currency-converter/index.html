Uma rápida conversão de referência

Este conversor calcula uma taxa cruzada a partir do conjunto de dados de taxa de referência mais recente disponível. É útil para estimativas e comparações, mas um banco, cartão ou serviço de câmbio pode oferecer uma taxa de transação diferente.
